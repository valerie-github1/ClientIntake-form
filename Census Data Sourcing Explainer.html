How the Census Data Was Found & Downloaded

A step-by-step breakdown of the data sourcing process for your Visual Analytics coursework

1

Starting Point — The Nomisweb Census Portal

Nomisweb (nomisweb.co.uk) is the official UK government portal run by the Office for National Statistics (ONS). It hosts all UK census microdata. Each census table has a permanent URL in this format:

https://www.nomisweb.co.uk/census/2011/dc2201ew

Where dc2201ew is the table code assigned by ONS — every table has a unique code. The ones used in this project:

DC2201EW — Ethnic × Religion KS209EW — Religion KS201EW — Ethnic Group KS202EW — National Identity
2

Finding the Download Button on Each Page

Each Nomisweb table page has a section called "Download the entire table for all areas". This reveals a dropdown to select your geography level (e.g. Local Authority), and a Download CSV button. When clicked, the browser submits a HTTP GET request to the Nomisweb API.

API URL revealed

By inspecting the form action URL, the underlying Nomisweb REST API endpoint was found:

https://www.nomisweb.co.uk/api/v01/dataset/nm_659_1.bulk.csv
  ?time=latest
  &measures=20100
  &geography=TYPE464
What each part means:
 • nm_659_1 = the internal Nomisweb dataset ID for DC2201EW
 • measures=20100 = count (not percentage)
 • geography=TYPE464 = Local Authority District level (see Step 3)
3

The Geography Code — What is TYPE464?

Nomisweb uses TYPE codes to specify which level of geography you want data at. Every geography level in England and Wales has a code. We used TYPE464 which is the "Local Authority District / Unitary Authority (prior to April 2015)" level — giving one row per local authority area.

TYPE464 was chosen because it gives 348 local authority areas — granular enough to see regional patterns, but not so small that it's unmanageable in Tableau.

5

2021 Data — A Different System (Bulk ZIP Downloads)

The 2021 census uses a different download system. Instead of the Nomisweb API, ONS provides pre-packaged ZIP files on the bulk downloads page: nomisweb.co.uk/sources/census_2021_bulk

Each ZIP contains CSVs for every geography level. The naming convention is:

census2021-ts021-ltla.csv

ts021 = table code  |  ltla = Lower Tier Local Authority (= LAD level)

The ZIP file URLs follow a consistent pattern:

https://www.nomisweb.co.uk/output/census/2021/census2021-TSCODE.zip
Table CodeTable NameZIP URLFile inside ZIP
TS021 Ethnic Group census2021-ts021.zip census2021-ts021-ltla.csv
TS030 Religion census2021-ts030.zip census2021-ts030-ltla.csv
TS028 National Identity (detailed) census2021-ts028.zip census2021-ts028-ltla.csv
TS031 Religion (detailed — bonus) census2021-ts031.zip census2021-ts031-ltla.csv
Important correction during download: TS031 turned out to be "Religion (detailed)" not "National Identity". The correct national identity table is TS028. This was discovered by downloading and checking the column headers of the file.
6

Geography Mismatch — 348 vs 331 Areas

You will notice the 2011 data has 348 local authorities and 2021 has 331. This is because local authority boundaries changed between censuses — some LAs were merged, split, or renamed. This is a known issue the ONS addresses directly.

2011 Census → 348 Local Authority Districts 2021 Census → 331 Local Authority Districts

How to handle this in your report: Use the ONS boundary change lookup to remap 2011 codes to 2021 boundaries. The ONS provides a lookup file for this:

https://www.ons.gov.uk/releases/censusmapsupdatechangeovertime

In Python, you join the 2011 data to the boundary lookup table using the geography code column (e.g. E06000005), then aggregate any 2011 areas that were merged into a single 2021 area.
