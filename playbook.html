The Big Picture

You are exploring how people in England and Wales describe their religion, ethnicity, and national identity — and how those things changed between the 2011 census and the 2021 census.

Between 2011 and 2021, the number of people reporting "No religion" doubled. Christianity fell below 50% for the first time. Immigration reshaped some areas. Your job is to find where these changes happened — and show it visually.

2.3 — Geography Mismatch: 348 vs 331 Areas

You will notice the 2011 data has 348 local authorities and 2021 has 331. This is because local authority boundaries changed between censuses — some were merged or renamed.

This is a known issue. ONS provides a boundary change lookup at: ons.gov.uk/releases/censusmapsupdatechangeovertime.

In Python, you join the 2011 data to the lookup table using the geography code column (e.g. E06000005), then aggregate any 2011 areas that were merged into a single 2021 area. Note this in your report's Data Preparation section.

Cleaning the Data in Python
Transform raw downloaded CSVs into clean, analysis-ready files
The Golden Rule of Data Cleaning

Never edit files in data/raw/ — those are your originals. Python reads from raw/ and writes cleaned outputs to clean/. Raw files are never changed. If something goes wrong, you can always re-read the originals.

What Does Cleaning Do? (5 steps)

  1. Load the file: Python reads the CSV into a DataFrame (think of it as an in-memory spreadsheet)

  2. Remove header rows: Nomisweb adds extra metadata rows at the top. The script skips these to find the real data

  3. Rename columns: Replace long, unwieldy column names (e.g. "Religion: All categories: Religion; measures: Value") with short names (e.g. total, christian, muslim)

  4. Convert to percentages: Divide each religion/ethnicity column by the total population column × 100 — so areas of different sizes become comparable

  5. Handle missing values: Note areas with zero population or blank entries. Use Bayesian imputation where required (see Section 4)

The One Line that Loads a File
# Load the 2011 religion file into Python
import pandas as pd

df = pd.read_csv('data/raw/2011/ks209ew_religion.csv')

# df is now a DataFrame — a table with 348 rows and 15 columns
# You never need to open the file in Excel

pandas is the Python library for working with tables. read_csv() reads a CSV file and turns it into a DataFrame you can work with in code.

Python Analysis: PCA, t-SNE & Bayesian
Three techniques — what they are, how to run them, what they output
Why We Need These Techniques

After cleaning, each of the 348 local authority areas has 17 percentage columns — % Christian, % Muslim, % Hindu, % White British, % Asian, % English identity, etc. It's impossible for a human to make sense of 17 numbers per area at once.

These three techniques solve the same core problem in different ways: how do we find patterns when there are too many variables to look at simultaneously?

PCA — Principal Component Analysis
32% + 20% = explains most variation

What it does: Takes 17 variables per area and condenses them into 3 "summary scores" (called components), while keeping as much information as possible.

Plain English: Imagine describing 30 students using 17 measurements each. PCA notices that maths, science, and physics scores always go up and down together — so it creates one "academic ability" score. Height and weight move together — so it creates a "physical build" score. Three summaries capture most of what 17 columns were saying.

For our data: PC1 will likely represent "how rural-traditional English vs diverse urban" each area is — because % Christian, % White British, and % English identity tend to rise and fall together.

Tableau output: A scatter plot of PC1 vs PC2. Each dot is a local authority. Areas close together have similar identity profiles.

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import pandas as pd

df = pd.read_csv('data/clean/religion_combined.csv')
features = ['pct_christian', 'pct_muslim', 'pct_hindu', 'pct_no_religion']

scaler = StandardScaler()
X_scaled = scaler.fit_transform(df[features])

pca = PCA(n_components=3)
components = pca.fit_transform(X_scaled)

# Save output for Tableau
out = df[['geography_code', 'geography']].copy()
out['PC1'] = components[:, 0]
out['PC2'] = components[:, 1]
out['PC3'] = components[:, 2]
out.to_csv('data/projections/pca_output.csv', index=False)
ℹ️
Always standardise (StandardScaler) before running PCA. If you don't, variables with larger numbers dominate the result even if they're not more important.
t-SNE — t-distributed Stochastic Neighbour Embedding
Cluster & similarity map

What it does: Places all 348 areas on a 2D map so that areas with similar identity profiles end up near each other. It focuses on preserving local structure — neighbours in the original 17-dimensional space stay neighbours in the 2D plot.

Plain English: Imagine you had to arrange 348 cities on a table so that cities with similar demographics sat next to each other. t-SNE does this mathematically. London boroughs will cluster together. Rural Welsh councils will cluster. Market towns in the Midlands will form their own group.

Key difference from PCA: PCA is about explaining variance and is interpretable (axes have meaning). t-SNE is about revealing cluster structure — the axes have no independent meaning, only the positions relative to each other matter.

from sklearn.manifold import TSNE

tsne = TSNE(n_components=2, perplexity=30, random_state=42, n_iter=1000)
tsne_result = tsne.fit_transform(X_scaled)

out['Dim1'] = tsne_result[:, 0]
out['Dim2'] = tsne_result[:, 1]
out.to_csv('data/projections/tsne_output.csv', index=False)
⏱️
t-SNE takes about 30 seconds to run. This is normal — do not close the terminal window. The cursor returns when it's done.
Bayesian Analysis — Credible Intervals
Uncertainty quantification

What it does: Instead of reporting a single point estimate (e.g. "35% Christian"), Bayesian methods report a range: "we are 95% confident the true percentage is between 32% and 38%". Larger areas have narrower intervals (more data = more certainty).

Why it matters: Census data can have missing values, especially in small areas with very few respondents. Bayesian methods allow you to estimate missing values probabilistically rather than ignoring or arbitrarily filling them.

Acceptable approaches (choose one or combine):

Bayesian credible intervals for proportions Bayesian Linear Regression for imputation Beta-Binomial model for proportions Bayesian trend prediction (e.g. 2030 projection)

Minimum viable approach: Compute Beta-Binomial 95% credible intervals for the percentage of "No Religion" in each area and visualise as a bar chart with error bars in Tableau. Justify the choice in your report.

from scipy import stats
import numpy as np

# Beta distribution credible interval for a proportion
# alpha = successes (people with No Religion), beta = failures (others)
def credible_interval(count, total, confidence=0.95):
    alpha = count + 1
    beta = (total - count) + 1
    lo = stats.beta.ppf((1-confidence)/2, alpha, beta) * 100
    hi = stats.beta.ppf(1-(1-confidence)/2, alpha, beta) * 100
    return lo, hi

Building Your Tableau Dashboard
50 marks — the most important section of the assessment
What Your Dashboard Should Include

You need at least the following views. You can use more than one dashboard if needed — you don't have to fit everything on one screen.

  1. A choropleth map: Colour local authorities by a chosen variable (e.g. % No Religion change 2011→2021). Lets users see geographic patterns.

  2. A time comparison view: Show how a variable changed between 2011 and 2021. A bar chart with year as colour or a side-by-side view works well.

  3. PCA scatter plot: Import pca_output.csv and plot PC1 vs PC2. Colour by region. Add tooltips with area name.

  4. t-SNE cluster plot: Import tsne_output.csv and plot Dim1 vs Dim2. Colour by dominant religion or ethnicity cluster.

  5. Bayesian uncertainty chart: A bar chart with error bars showing credible intervals. Demonstrates uncertainty awareness.

Useful Features to Add
  • Toggle between absolute values and percentages (use a parameter)
  • Filter by region or year
  • Tooltips that identify the area name on every chart
  • A title and colour legend on every view
  • Text annotation explaining what each projection's axes represent
Common Mistakes to Avoid
  • Saving as .twb instead of .twbx (automatic zero for 50 marks)
  • Projection plots with no tooltip identifying the area
  • No explanation of what PC1 and PC2 represent
  • Comparing 2011 and 2021 without accounting for boundary changes
  • Choosing chart types without justifying them in the report
